# AI Sniper Trading Bot Terminal (US30, US500, US100)

An institutional-grade, responsive dark-mode MetaTrader 5 (MT5) style web terminal featuring automated AI market scanners, exact pip-calculated Entry, Stop Loss (SL), and Take Profit (TP) targets, live 1-hour candle countdown timers, and an integrated pre-access payment unlock flow.

## Features
* **MT5 Institutional UI/UX:** Styled with dark terminal aesthetics, monospace numerical fonts, and real-time asset tracking cards.
* **Multi-Index AI Scanner:** Monitors and evaluates live price action feeds for **US30**, **US500**, and **US100** indices.
* **Precise Sniper Signals:** Generates clear Buy/Sell directional badges with exact calculated Entry, SL, and TP levels.
* **Pre-Access Payment Gate:** Features a simulated M-Pesa instant payment prompt step required before unlocking live terminal data and signals.
* **Live Activity Logs:** Real-time execution stream mimicking automated trading terminal logs and volatility adjustments.

## Tech Stack
* **HTML5:** Semantic document structure.
* **CSS3:** Custom responsive styling utilizing CSS variables, Flexbox, and Grid layouts.
* **JavaScript (ES6):** Dynamic paywall unlocking, asynchronous ticker fluctuations, and countdown timer logic.
